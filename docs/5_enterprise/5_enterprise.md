Sage.is AI-UI is completely free to use, with no restrictions or hidden limits. We publish Sage.is AI-UI under the [AGPL](../glossary#agpl).  AGPL extends GPL's share-alike rule to cover network use: any modified version served over a network must provide source code to users and this stops SaaS.

We guaranty all end-users get complete, corresponding source for any interacted instance, enabling audits, self-hosting, and modifications — core [[glossary#OSI/FSF|OSI/FSF]] principles.

# Sage.is AI-UI Glossary

## AGPL

The [AGPL](https://opensource.org/license/agpl-v3), short for the [Affero General Public License](https://opensource.org/licenses/AGPL-3.0) is an[ Open Source licence](https://opensource.org/osd) approved by the OSI, more specifically a strong [copyleft license](https://en.wikipedia.org/wiki/Copyleft#Types_and_relation_to_other_licenses). Most importantly it guarantees you the opportunity to receive the Corresponding Source of your applications licenced under the AGPL by providing access to the Corresponding Source from a network server at no charge, through some standard or customary means of facilitating copying of software.

## FOSS

**Free and open-source software** (**FOSS**) is software that gives users the right to use, share, modify, and distribute the software – modified or not – to everyone and provides the means to exercise those rights using the software's source code. FOSS is an inclusive umbrella term encompassing free software and open-source software. The rights guaranteed by FOSS originate from the "Four Essential Freedoms" of _[The Free Software Definition](https://www.fsf.org/about/what-is-free-software)_ and the criteria of _[The Open Source Definition](https://opensource.org/osd) 

All FOSS can have publicly available [source code](https://en.wikipedia.org/wiki/Source_code "Source code"), but not all [source-available software](https://en.wikipedia.org/wiki/Source-available_software "Source-available software") is FOSS. FOSS is the opposite of [proprietary software](https://en.wikipedia.org/wiki/Proprietary_software "Proprietary software"), which is licensed restrictively or has undisclosed source code.

## OSI/FSF

The [Open Source Initiative](https://opensource.org/) (OSI) is one of many organization keeping a list of open-source licenses. The [Free Software Foundation](https://www.fsf.org/) (FSF) maintains a list of what it considers free. FSF's [free software](https://www.fsf.org/about/what-is-free-software) and OSI's [open-source](https://opensource.org/licenses) licenses together are called [FOSS](https://en.wikipedia.org/wiki/Free_and_open-source_software "Free and open-source software") (Free and Open Source Software) licenses.

## CLI

A command line interface (CLI) is software you use to interact with your operating system using your keyboard. With a command line interface, you can enter text commands to configure, navigate, or run programs on any server or computer system. All operating systems—including Linux, macOS, and Windows—provide a CLI for faster system interaction.

Another mechanism is a graphical UI ([[#GUI]]), which is popular today with all applications and software systems. You can use a [[#GUI]] to visually navigate and click on icons and images to make things work. However, a [[#GUI]] is inefficient for system administration tasks, especially if the environment is virtual or remote.

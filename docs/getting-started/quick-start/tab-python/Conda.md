
# Install with Conda

1. **Create a Conda Environment:**

   ```bash
   conda create -n sage-is-ai-ui python=3.11
   ```

2. **Activate the Environment:**

   ```bash
   conda activate sage-is-ai-ui
   ```

3. **Install Sage.is AI-UI:**

   ```bash
   pip install sage-is-ai-ui
   ```

4. **Start the Server:**

   ```bash
   sage-is-ai-ui serve
   ```
